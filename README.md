# Product counts and recall-event counts

Study 17 of the independent 50-study program. This study asks how the counting unit changes an internal data-review queue built from FDA food enforcement records. A recall event can contain several legitimate product records. Counting them as separate events can change a queue's threshold triggers; the product records themselves remain useful and must be retained.

**Current state: protocol fixed before full retrieval and analysis. No results yet.**

The audience is research and data-engineering reviewers. This is a retrospective snapshot comparison, not a public recall-alert service, a medical decision tool or a reconstruction of recall amendments. See [PROTOCOL.md](PROTOCOL.md), [SOURCES.md](SOURCES.md) and [DATA_RIGHTS.md](DATA_RIGHTS.md).
